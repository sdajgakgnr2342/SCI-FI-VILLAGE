# 服务器匹配与人机村民

## 真人服务器均衡（每服上限 100）

采用 **Fill-first（优先填满）**：

1. 新玩家进入「已开放且未满」中**人数最多**的服  
2. 仅当所有开放服都 ≥ 70 人时，才把待命服升为开放  
3. 某服真人 ≤ 8，且还有其他热闹服时，标记为「排空中」，拒绝新进，避免长期「一服几个人」  
4. 人机**不占** 100 人容量

## 玩家 : 人机

人机是**本地氛围 NPC**，不是假在线人数：

| 附近真人 | 人机 |
|---------|------|
| 0~2 | 最多 1~2 个偶尔出现 |
| ≥3 | 不再刷人机 |

生命周期：`enter → linger → depart → exit`

- **出现**：侧后方盲区生成，缩放淡入  
- **停留**：在附近闲逛 40~90 秒  
- **离开**：走向玩家背后/盲区，目标不断外推（越走越远）  
- **消失**：距离足够远 **且** 不在视野内（或淡出完毕）才销毁——**禁止视野内瞬删**
